# VeriKVM

**一个无需代理的软件 KVM，像人一样操作你自己的机器。**

它在你的第二台机器上执行真实任务：**读取屏幕、判断当前所处的状态，然后打字和点击**
—— 在目标机看来，这就是一套真实的物理键盘和鼠标。目标机上不安装任何东西。

与其他任何软件 KVM 不同，它**在每次操作前都会校验屏幕，并拒绝在错误的窗口中操作**
—— 因此任务绝不会落在锁屏或错误的应用上。

> **用于你自己的机器。** 你的两台机器、两根线，加上你自己。范围与威胁模型见
> [SECURITY.md](SECURITY.md)。

## 它能自动化什么

VeriKVM 省下你盯着第二台电脑的时间。你用 JSON 描述小任务（或复用示例），它就会完成
人们最常自动化的日常与工作中的桌面操作 —— 并且只在屏幕正是任务所预期的那个时才动手：

- **回复聊天和消息** —— WhatsApp Web、Telegram、Slack、Teams：发现新消息、打出回复、发送。
- **让机器保持活动、不休眠** —— 在长时间任务期间阻止它睡眠、锁屏或进入空闲，无需更改
  电源设置。
- **回复和分拣邮件** —— 打开客户端、读取屏幕内容、打出回复、归档。
- **编辑电子表格** —— 打开 Excel 或 Google Sheets、录入行、触发重新计算、保存。
- **填写表单和录入数据** —— 向没有 API 的网页或桌面应用重复输入。
- **操作拒绝机器人和宏的应用** —— 由于输入是真实的 USB-HID，连屏蔽脚本的软件也会照单全收。
- **夜间无人值守地批量运行** —— 把任务排成队列；它会先校验每一个屏幕，所以不会在错误的
  窗口中触发。
- **远程操作第二台（或无显示器的）电脑** —— 那台机器上不装代理、驱动或远程桌面软件。

一句话：**面向第二台电脑的、无需代理的桌面自动化（RPA）**，配合屏幕校验，让任务绝不会
打字到错误的地方。

## 为什么是它

其他软件 KVM 都在盲目转发你的按键 —— 它不知道哪个窗口获得了焦点，重新锁定的屏幕会吞掉
你的输入，而且即使什么都没发生，它也报告"发送成功"。VeriKVM 像一个坐在键盘前的人那样闭环：

1. **读取屏幕。** 采集 HDMI 画面并对屏幕上真正显示的内容进行分类 —— 桌面、正确的应用、
   锁屏、对话框。
2. **判断状态。** 如果屏幕不是任务所预期的，它会拒绝整个批次，而不是打字到错误的地方。
3. **在真实硬件上动作。** 通过 CH9329 打字和点击，然后回读屏幕以确认操作确实生效。

这正是硬件 KVM 和软件 KVM 两派都略过的一点，因为它们只转发输入，从不需要去信任一张截图。

## 它是什么 —— 又不是什么

**它是**一个面向操作系统正在运行的机器的、系统级的自动化与远程控制工具。无代理、无驱动、
目标机上也没有远程桌面软件 —— 它看起来就像一个坐在键盘前的人。

**它不是**硬件 KVM。**没有电源控制、没有 BIOS/UEFI 访问、没有虚拟介质。** 如果你需要
开机前控制，请使用基于树莓派的 IP-KVM（PiKVM、TinyPilot）。诚实的边界见
[HARDWARE.md](HARDWARE.md)。

## 特性

- **故障即关闭（fail-closed）校验** —— 每次操作前对屏幕分类，拒绝错误状态，并通过回读
  确认每一次操作。
- **真实 HID 输入** —— 一个 CH9329 桥接器，目标机无法将它与物理键鼠区分开。无代理。
- **国际键盘** —— 可插拔布局（US、ABNT2 等）。当前布局无法产生的字符会被拒绝，绝不会
  以错误的字形输出。
- **实测，而非猜测** —— 一份记录了我们所测量到的各种古怪之处的[硬件指南](HARDWARE.md)，
  以及一本记录了什么出错、为何出错的[工程日志](LEARNINGS.md)。

## 如何连接

```
[ 目标机 ] --HDMI out--> [ 采集 dongle ]     --USB--> [ 控制机 ]
[ 目标机 ] <--USB HID--- [ CH9329 + CH340 ] <--USB-- [ 控制机 ]
```

两台机器、两根线。控制机写入 JSON 任务文件；守护进程在目标机上执行它们并回读屏幕。
配件清单（约 US$15–25）见 [HARDWARE.md](HARDWARE.md)。

## 快速开始

```bash
git clone https://github.com/bittricks/verikvm
cd verikvm
pip install -r requirements.txt

# 启动守护进程（自动检测串口；--layout 设置目标机键盘布局，默认 abnt2）
python src/agent_daemon.py --layout us
```

完整的安装、接线与校准见 [`docs/`](docs/)。

## 安全

它用你的凭据控制你自己的一台机器。**默认不开放任何网络端口** —— 它与硬件通信，而非
网络。在对外暴露任何东西之前，以及要报告漏洞时，请阅读 [SECURITY.md](SECURITY.md)。
